# Projeto PRF 2025 — Análise Exploratória no Excel/Sheets

## Objetivo
Explorar a base de acidentes da PRF no Excel/Google Sheets, construindo tabelas dinâmicas e gráficos para identificar padrões de sinistralidade.

## Arquivos
- `atvd_02_excel_prf_ruan_gualberto.xlsx`: planilha com a base tratada (`tb_acidentes_prf`, `dados`), dicionário de dados (`dicionario_resumido`), tabelas dinâmicas (`tabelas_dinamicas`), gráficos (`graficos`) e observações da análise (`observacoes`).
- `link do sheets.txt`: link para a versão da planilha no Google Sheets.

## Observação metodológica
Análise focada em distribuição espacial, causa x gravidade dos acidentes e fatores de risco ambientais/temporais, com destaque para os estados SP, PE e MG.
