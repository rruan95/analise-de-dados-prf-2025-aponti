# Aponti - Módulo 1: Análise de Dados PRF

Atividades do Módulo 1 do curso de Análise de Dados da Aponti.

## Estrutura

- **atvd1/** - Prévia inicial dos dados (`Dados PRF - Prévia.xlsx`)
- **atvd2/** - Análise exploratória no utilizando o Sheets
- **atvd3/** - Análise em SQL, com views e indicadores
- **atvd4/** - Preparação de dados (CRISP-DM) em Python e Jupyter, gerando bases para EDA e modelagem
